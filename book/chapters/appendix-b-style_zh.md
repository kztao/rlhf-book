# 超越"只是风格"

RLHF 的早期发展使其获得了"只是风格迁移"的声誉；其他尖锐的批评集中在 RLHF 如何操纵输出中信息的呈现方式。
本附录解释了为什么风格是理解 RLHF 提供的价值的核心——以及为什么它积极影响模型能力和用户体验。

RLHF 仅关于风格迁移的想法因两个原因阻碍了 RLHF 叙事。
首先是 RLHF 如何与对模型的小的、不重要的变化相关联。
当人们讨论风格迁移时，他们并不将其描述为重要或令人兴奋的——他们认为它是表面性的。
然而，风格是人类价值的无尽来源；这就是为什么复述故事可以产生新的畅销书（如 Sapiens），它是继续推进我们知识生态系统的根本部分。
风格与信息是什么交织在一起。

第二个原因是许多人忽视了做得好的 RLHF 提升流行 LLM 评估分数的事实。
我们已经看到不同风格如何实际上可以有意义地通过 Llama 3 改进评估 [@dubey2024llama]。
Llama 3 Instruct 模型在 Arena 上得分极高，这被接受为因为它们有更有趣的个性——它们比同时代其他模型更简洁和聪明。
无论许多 LLM 用户痴迷的基准分数如何，如果 RLHF 将使语言模型更简单地更有趣，那就是已交付的价值。

贯穿本附录，术语"聊天性"用于涵盖使用 RLHF 训练的模型回答日益增长的长度，但它也涵盖大量 markdown 使用、表情符号和以项目符号列表格式化答案等技术。

## 聊天性平衡

RLHF 或偏好微调方法被无数人用于提升像 AlpacaEval 和其他自动聊天排行榜的分数，但 RLHF 在此处赋予的巨大收益并没有按比例转移到更难操作的评估如 Arena 上。
张力在于，虽然 RLHF 方法对这些模型给出了可衡量的改进，但该训练并不总是转化为人们关心的性能。
通过 RLHF 文献的建立，大量模型已发布使用相关方法提升模型的"对齐"，但它们通常做得太过，并发布了从误导到无意义的评估分数。

这些由对齐激发的 RLHF 方法，当做得正确时，使模型更易于使用且更愉快。
这通常伴随着在 MT Bench 或 AlpacaEval 等评估工具上的明显改进。

在 2023 年秋季，关于直接偏好优化（DPO）及其相对于近端策略优化（PPO）和其他基于 RL 的偏好微调方法的角色的辩论达到顶峰——聊天评估与现实世界性能的平衡是此辩论的核心。
问题是你也可以使用像 DPO 和 PPO 这样的技术在反馈循环或大量数据中，以这些聊天性能为代价严重损害模型在数学或编程等其他任务上的表现。

一个自然的问题是：为什么 RLHF 使模型回答更长？
从根本上，像 Arena 这样的评估向我们展示，模型的普通用户在与简练回答比较时通常喜欢更长、更完整的答案。
更长的答案在快速评估它们的用户看来可能感觉更彻底、更有帮助甚至更可信。
这不代表*每个*用户的偏好，但这些模型被训练以匹配许多数据标注者的平均偏好，因此 RLHF 倾向于使模型更加冗长。
